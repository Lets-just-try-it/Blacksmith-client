## 주요 요청

1. 영입한 모험가에 친밀도(최대 100)를 넣고, 행동별로 쌓이는 양을 제안한다.
2. 여관 모험가와 대화하면 친밀도가 오르게 연결한다.
3. 친밀도를 Game 씬에서 볼 수 있게 한다.
4. 친밀도 전투 이벤트(빠른 회복, 사망 면제, 스킬 강화)를 구현한다.
5. 작업을 기능별로 나눠 커밋한다.

## AI와 논의한 내용

### 증감량과 속도

AI가 처음 제안한 증감량은 100까지 15~17일이 걸렸다. 사용자가 너무 길다고 해 대화 +5, 직접 파견 +3 등으로 높였다. 기본 행동만 하면 약 9일, 장비·치료까지 챙기면 6~7일이 걸린다. 같은 행동을 반복하는 것을 막으려고 행동마다 하루 1회 제한과 하루 최대 +15를 두었다.

### 친밀도를 볼 곳

친밀도가 Fusion 네트워크 배열 안에 있어 인스펙터에 보이지 않았다. 목록 창은 여관이 없는 PlazaTest에만 있었다. AI가 Game 씬에 목록 창을 배치하는 방법과 여관 이름표에 표시하는 방법을 제시했고, 사용자가 목록 창을 골랐다.

### 대화 중 Enter 문제

사용자가 대화 중 Enter를 누르면 목록 창이 열리고, 의도하지 않았는데 밤으로 넘어간다고 알렸다. AI가 원인을 찾았다. 마우스로 누른 버튼이 선택된 채 남아, 대사를 넘기는 키와 같은 UI/Submit(Enter)에 다시 눌린 것이다. 낮 길이는 600초여서 시간이 다 된 것은 아니었다. 두 버튼만 Navigation None으로 고쳤다. 같은 설정인 다른 영역 버튼 23개는 사용자가 아직 고치지 않기로 했다.

### 전투 이벤트 수치

AI가 발동 단계, 확률, 효과를 선택지로 물었다. 사용자는 단계별 발동(빠른 회복·스킬 강화는 신뢰, 사망 면제는 맹세), 빠른 회복 10%·스킬 강화 5~10%·사망 면제 5% 이하, 효과 부상 절반·생존·+50%를 골랐다. AI는 범위로 받은 값을 이렇게 정했다. 스킬 강화는 친밀도 50에서 5%, 100에서 10%로 비례하고, 사망 면제는 5%다.

## 주요 결정

- 사용자 결정
  - 최대 100, 영입 시 10, 중상이면 감소, 단계(낯섦·친근·신뢰·맹세).
  - 증감 속도를 높인다.
  - Game 씬에 목록 창을 둔다.
  - 전투 이벤트의 단계, 확률 범위, 효과.
- 구현 중 정한 것
  - 중상 기준은 파견 불가 부상(50 이상)과 같다.
  - 대화창이 열리는 순간 친밀도가 오른다.
  - 사망 면제는 루비 목걸이보다 먼저 판정한다.
  - 빠른 회복은 사망 판정 전에 부상을 줄인다.
  - 결과창에는 짧은 이름으로 표시한다.
