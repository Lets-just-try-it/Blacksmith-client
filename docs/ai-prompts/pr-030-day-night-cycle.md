# PR #30: feat: 낮·밤 사이클과 영업 마감, 밤 전환 연출, 밤 파견 연결

## 개요

- 브랜치: `feat/day-night-cycle`
- 대상 브랜치: `dev`
- PR: #30
- 작성일: 2026-11-04
- 담당 영역: 대장간(낮·밤 전환), 전투(밤 파견 연결)
- 작업 목적: 낮 영업 → 밤 파견 → 다음 날로 이어지는 낮·밤 사이클 구현과 진행 문서 가독성 개선

## 주요 요청

1. 낮·밤 시스템을 구현할 것
2. 진행 문서의 시스템별 구현 현황을 "항목 + 목록" 형식으로 바꿀 것
3. 낮을 카운트다운이 아니라 10시~20시(10시간을 10분으로)로 표기할 것
4. 왼쪽 위에 아날로그 시계(흐른 시간을 부채꼴로)를 두고, 아래에 "10:10"처럼 10분 단위로 바뀌는 디지털 시계를 둘 것
5. 밤이 되면 바로 파견 창을 띄우지 말고, 시간을 멈추고 화면 가운데에 "밤이 되었습니다"를 띄우고 조명을 어둡게 한 뒤 파견 창을 띄울 것
6. 파견 창이 열린 동안 하단 개인 슬롯을 숨길 것
7. 커밋을 기능별로 나눌 것
8. PR #29가 squash로 병합되면 이 브랜치를 새 dev 위로 다시 쌓을 것

## AI와 논의한 내용

### PR #29와의 충돌

밤에 파견 창을 여는 코드가 병합 전인 PR #29에 있었다. AI는 두 가지를 설명했다.
- 코드: #29 위에 쌓으면 충돌이 거의 없다.
- 문서: 진행 문서 형식 변경은 #29와 같은 줄을 건드린다.

사용자는 #29 위에 쌓기로 했다. #29가 squash로 병합된 뒤에는, AI가 병합된 내용이 #29 브랜치와 같은지 확인하고 낮·밤 커밋만 새 dev 위로 옮겼다.

### 상태 위치

AI는 대장간 영역에 상태를 따로 두는 안을 추천했다. 사용자는 공용 `Network/GameState`에 두기로 했다.

### 정하지 않은 기획

AI가 물은 항목과 사용자의 결정은 다음과 같다.
- 밤에 파견하지 않고 다음 날로 넘기기: 기획에 없던 내용이고, 건강한 모험가가 없으면 밤에서 멈추게 되는 문제가 있었다. 사용자는 건너뛰기 버튼을 두기로 했다.
- 낮 시작 때 모험가 후보 다시 뽑기(기획 6.1절 [미정]): 이번에는 연결하지 않기로 했다.

### 낮 길이

사용자가 낮이 실제 10분인지 물었다. AI는 다음과 같이 설명했다.
- 실제 게임과 ForgeTest는 600초, DispatchTest만 테스트용 60초다.
- 타이머는 Fusion 틱 기반이라 실제 시간으로 흐른다.

### 진행 문서 형식

형식 변경과 낮·밤 내용이 같은 문서에 섞여 있었다. AI는 변경 전 문서에 형식 변경만 적용한 커밋을 따로 두었다.

## 주요 결정

- 낮·밤 단계는 `GameState`가 `[Networked]`로 동기화한다. 단계 흐름은 낮 → 영업 마감 중 → 밤 전환 → 밤이다.
- 낮이 끝날 때 진행 중인 미니게임이 있으면 모두 끝나기를 기다린다. 낮이 아니면 새 미니게임을 시작할 수 없다.
- 시계는 낮 10분을 게임 속 10시~20시로 보여 준다(실제 1초 = 게임 1분).
  - 아날로그: 10시 방향부터 지금 시각까지 부채꼴
  - 디지털: 24시간제, 10분 단위
- 밤 전환 연출은 3초다([추정]).
  - 시간 정지, "밤이 되었습니다", 조작 잠금, 조명 어둡게
  - 문구가 사라진 뒤 파견 창이 뜬다.
- 밤 파견 창은 닫을 수 없고 "파견하지 않고 다음 날"로 넘길 수 있다. 전투 결과를 확인하면 다음 날이 시작된다.
- 파견 창이 열린 동안 하단 개인 슬롯을 숨긴다.
- 낮 시작 때 후보 다시 뽑기와 밤 저장은 이번에 하지 않는다.

- EditMode 테스트 252개 통과. 낮·밤 단계·시각 규칙 테스트 10개를 추가했다.
- `DispatchTest` 플레이 모드에서 다음을 확인했다. 콘솔 오류 없음.
  - 시계가 흐르는 것
  - 낮이 끝나면 약 3초 동안 전환 연출이 이어지는 것 (로그로 간격 확인)
  - 밤 파견 창, 건너뛰기, 밤에 파견한 뒤 다음 날 시작
  - 조명이 어두워졌다가 되돌아오는 것
  - 하단 개인 슬롯 숨김
- `ForgeTest` 플레이 모드에서 다음을 확인했다.
  - 실제 1초에 게임 1분씩 흐르는 것
  - 영업 마감 중 대기와 밤에 작업대 시작 요청 거절
- 화면 캡처로 시계, 전환 문구, 어두운 조명, 파견 창을 확인했다.
- 작업 중 확인하고 고친 것
  - 전환 문구가 파견 창과 겹쳐 문구가 먼저 사라지게 했다.
  - 밤 파견 창을 낮용으로 다시 열면 건너뛰기 버튼이 사라져, 밤 창으로 남게 했다.
  - ForgeTest에서 시계가 테스트용 카메라 안내 문구와 겹쳐 아래로 내렸다.
- 다시 쌓은 뒤의 파일 내용이 테스트한 상태와 같은 것을 확인했다.
- 실제 미니게임 도중 낮이 끝나는 경우, 실제 마우스, 두 명 접속은 확인하지 못했다.
