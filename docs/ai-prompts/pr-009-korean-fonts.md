- 작업 목적: UI 한글이 네모로 보이는 문제를 풀기 위해 게임 분위기에 맞는 한글 폰트를 임시로 추가한다.

## 주요 요청

1. 게임 느낌에 맞는 한글 폰트를 추천받고, 후보가 실제로 어떻게 보이는지 확인할 것
2. 주아와 고운바탕을 추가하고 앞으로 UI에 적절히 적용할 것
3. 현재 추가하는 폰트는 확정이 아닌 임시 단계일 것

## AI와 논의한 내용

### 폰트 후보와 견본

AI가 상업적으로 쓸 수 있는 무료 폰트를 용도별로 추천했다(고운바탕, 나눔명조, Noto Serif KR, Pretendard, 둥근모꼴, 주아). 사용자가 실제 모양을 보고 싶다고 해서 담금질 결과창 문구로 비교하는 견본 페이지를 만들었다. Pretendard와 둥근모꼴은 견본 페이지에서 불러올 수 없어 제외했고, Pretendard 대신 같은 계열의 Noto Sans KR로 보여 주었다.

### 라이선스

사용자가 주아를 써도 되는지 물었다. AI가 주아는 SIL OFL 1.1로 상업 게임 사용과 임베딩이 가능하다고 설명했고, 지킬 점으로 폰트 단독 판매 금지, 폰트 파일을 배포할 때 라이선스 문서 동봉, 수정 배포 시 원래 이름 사용 금지를 안내했다. 라이선스 표기는 받는 곳에서 한 번 더 확인하도록 했다.

### 폰트 폴더 위치

AI가 폰트를 `05.Art/` 아래에 두자고 했으나 사용자가 문서에 있는 내용인지 물었다. 확인해 보니 `CLAUDE.md`에 폰트 폴더 규칙이 없었고 AI의 추측이었다. 선택지를 비교해 `05.Art/Fonts/`로 정했다.

### 작업 순서와 적용 범위

폰트 작업 시점에 담금질 입력 작업이 커밋 전이었다. 담금질을 먼저 커밋한 뒤 `dev`에서 폰트 브랜치를 따로 만들어 PR이 섞이지 않게 했다. 폰트가 임시 단계라서 TMP 기본 폰트 설정은 바꾸지 않고, 팀원의 기존 화면에 영향이 없도록 했다.

## 주요 결정

- 임시 폰트는 주아와 고운바탕이다. 확정이 아니다. (사용자 결정)
- 폰트 파일은 `05.Art/Fonts/`에 두고 `CLAUDE.md` 폴더 구조에 반영한다. (사용자 결정)
- 폰트 파일은 GitHub `google/fonts` 저장소에서 내려받는다. (사용자 승인)
- 한글은 글리프가 필요할 때 채워지는 Dynamic TMP 폰트 에셋으로 만든다. (AI 제안)
- TMP 기본 폰트는 바꾸지 않고, 기존 UI에는 적용하지 않는다. (AI 제안, 사용자 승인)
- 폴더 구조 변경은 기획 변경이 아닌 프로젝트 규칙 변경이며 팀 공유가 필요하다.

- 에디터에서 한글 문구로 세 TMP 에셋 모두 글리프가 빠짐없이 추가되는 것을 확인했다.
- 에디터 콘솔 오류 없음.
- 실제 UI에 적용한 화면은 이번 PR에 없어 확인하지 않았다.

## AI 활용 범위

AI가 폰트 추천과 견본 페이지 제작, 라이선스 설명, 폰트 파일 내려받기, TMP 폰트 에셋 생성, 글리프 검증, 문서 수정을 맡았다. 사용자는 사용할 폰트, 폴더 위치, 파일 내려받기, 임시 단계라는 범위를 직접 결정했다. 커밋과 PR 내용은 AI가 초안을 보이고 사용자가 승인했다. 폴더 구조 변경의 팀 공유는 사용자가 직접 한다.
