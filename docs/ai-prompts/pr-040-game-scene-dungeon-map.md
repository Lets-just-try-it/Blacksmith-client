## AI와 논의한 내용

### "지도"가 가리키는 것과 현재 상태

AI가 기획·진행 문서와 씬을 확인했다. 그 결과 "지도"를 밤 파견의 던전 지도 창으로 보았다. Game 씬에는 `DispatchUI` 프리팹(지도 창 포함)과 `DispatchSession`, `NightDispatchLink`가 이미 배치되어 있었다. 다만 지도 창의 `_state`·`_progress`가 비어 있어, 밤에 파견 창부터 열리는 상태였다. 새로 만들 것은 없고, `DispatchTest`와 같은 방식으로 연결만 하면 된다고 판단했다.

### 연결 방법

프로젝트 규칙대로 씬 YAML을 직접 고치지 않았다. Unity CLI로 에디터에서 씬을 열어 두 필드를 연결하고 저장했다. 씬 변경은 프리팹 설정 두 줄뿐이다. 씬을 열 때 저절로 바뀐 폰트 에셋은 이번 작업과 관계없어 커밋에서 뺐다.

## 주요 결정

- Game 씬의 던전 지도 창을 `DispatchSession`의 `DispatchState`·`DungeonProgressState`에 연결한다. `DispatchUI` 프리팹과 지도 스크립트는 바꾸지 않는다.
- 진행 문서의 남은 작업에서, 이미 배치된 "`Game` 씬에 파견 창·`DispatchSession`·`DaySceneBattleCover` 배치"를 지운다.

## 변경된 주요 파일

- `Assets/01.Scenes/Game.unity`
- `docs/PROJECT_PROGRESS.md`

## 검증 내용

- 에디터 플레이 모드에서 Bootstrap → 로비 Host 시작 → Game으로 들어가 낮을 바로 끝냈다. 밤에 지도 창이 먼저 뜨고(거점 30개) 파견 창은 닫혀 있는 것을 확인했다.
- 파견 창 ↔ 지도 이동과, "파견하지 않고 다음 날"로 2일째 낮이 되며 지도가 닫히는 것을 확인했다. 콘솔 오류는 없었다.
- 버튼 대신 상태 함수를 직접 불렀다. 실제 마우스와 두 명 접속은 확인하지 않았다.

## AI 활용 범위

AI가 관련 문서와 씬 구성을 확인하고, Unity CLI로 씬 연결과 플레이 모드 검증을 하고, 진행 문서를 고쳤다. 사용자는 새 브랜치에서 작업할 것과 Game 씬에 지도를 넣는 것을 요청했고, 커밋과 PR 내용을 확인해 승인했다.
