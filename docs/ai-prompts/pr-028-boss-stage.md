# PR #28: feat: 보스 스테이지 등장 연출과 보스 크기·오라, 분노 효과 추가

## 개요

- 브랜치: `feat/boss-stage`
- 대상 브랜치: `dev`
- PR: #28
- 작성일: 2026-11-04
- 담당 영역: 전투
- 작업 목적: 보스 스테이지가 잡몹 스테이지와 확실히 다르게 느껴지도록, 보스만 나오게 하고 등장·외형·분노 연출을 더한다.

## 주요 요청

1. 보스 스테이지가 시작되면 "BOSS STAGE" 문구나 개별 효과로 긴장감을 높인다.
2. 보스 스테이지에는 특수한 경우를 빼고 잡몹 없이 보스만 나온다.
3. 보스는 압도적인 크기와 이펙트로 "어 얘 좀 다른데"라는 느낌을 준다.
4. 보스가 분노할 때도 효과를 추가한다.
5. 작업은 `dev`에서 새 브랜치로 한다.

## AI와 논의한 내용

### 기획 반영과 브랜치

AI가 먼저 `docs/GAME_CONCEPT.md` 7.1에 "보스 스테이지" 항목을 만들었고, 사용자가 구현까지 요청했다. 처음 문서를 고친 `docs/dungeon-tiers` 브랜치에는 10단계 기획 커밋이 있어서, AI가 브랜치 기준을 물었고 사용자가 `dev`에서 새로 만들기로 했다. 그래서 예외 문구는 10단계 근위 사제 대신 일반 문구로 적었다.

### 보스 수치

AI가 에디터에서 시뮬레이션을 돌려, 보스 스테이지에서 잡몹을 빼도 기존 클리어 기준(1단계 Lv5 2명·Lv1 3명, 2단계 Lv12 3명·Lv5 5명)이 그대로인 것을 확인했다. 보스 체력을 20% 올리면 같은 파티가 지기 시작해, 보스 수치는 바꾸지 않았다.

### 등장 연출과 재생 멈춤

전투 결과는 시뮬레이션으로 정해지므로, 연출 동안 화면 재생만 멈추는 `BattlePlayer.Hold`를 두었다. 멀티에서도 참가자마다 같은 시뮬레이션을 재생하므로 결과가 어긋나지 않는다.

### 분노 효과

분노 순간의 기존 빨간 파티클에 더해 몸 색 변화, 분노 오라, 카메라 흔들림, 체력바 표시를 넣었다. 플레이 모드 확인 중 보스가 쓰러진 뒤에도 오라가 결과창 위에 남는 것을 AI가 발견해, 쓰러질 때 오라를 멈추게 했다.

## 주요 결정

- 보스 스테이지에는 보스만 나온다. 예외는 단계 기획에 따로 적는다. (사용자 결정)
- 브랜치는 `dev`에서 새로 만든다. (사용자 결정)
- 1·2단계 보스 수치는 그대로 둔다. (AI 제안, 시뮬레이션 근거)
- 등장 연출은 모든 보스 공통의 "BOSS STAGE" 문구와 보스 이름으로 하고, 보스별 개별 연출은 필요할 때 더한다. 기획의 `[담당자 결정]` 항목을 이렇게 정리했다. (AI 제안)
- 보스 크기는 보스 공용 프리팹에서 1.5배, 등장 연출 길이는 2.2초로 두고 `[추정]`으로 표시한다. (AI 제안)
- 분노하면 몸이 붉어지고 분노 오라가 켜지며, 화면이 흔들리고, 체력바 이름 옆에 "분노"가 붙고 바 색이 바뀐다. (사용자 요청, 구체 효과는 AI 제안)

AI는 기획 문서 초안, 시뮬레이션 수치 확인, 코드 작성, Unity CLI를 통한 씬·프리팹·던전 데이터 수정, 플레이 모드 확인, 문서 갱신을 맡았다. 보스 스테이지 기획, 분노 효과 추가, 브랜치 기준, 커밋·푸시는 사용자가 정했다.
