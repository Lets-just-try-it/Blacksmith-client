## 주요 요청

1. 하루 사이클(코어 루프와 콘텐츠 루프)이 돌아가는지 확인할 것
2. 던전을 어디까지 할지 고르는 별도의 지도 창을 만들 것. 새 브랜치에서 작업하고, 낮 파견 창 버튼 제거는 따로 작업함
3. 지도는 임시 대륙 위에 스테이지를 선형으로 이어 표기할 것. 선은 길, 동그라미는 스테이지, 별은 보스이며, 지도 같은 그림으로 그려 적용할 것
4. `ForgeTest` 씬은 다른 담당자의 영역이므로 변경을 되돌리고 나중에 붙일 수 있게 할 것

## AI와 논의한 내용

### 하루 사이클 점검

AI가 코드를 추적하고 `ForgeTest` 플레이 모드에서 1일째 낮 → 밤 → 파견·전투 → 2일째 낮을 돌려 보았다. 하루 넘김 뼈대는 동작하지만 판매·골드, 전투 보상 반영, 대장간 업그레이드가 없어 루프가 닫히지 않는다고 정리했다. 확인 중 #32 병합 이후 `ForgeTestStarter`의 관리 목록 참조가 비어 있는 문제도 찾았다.

### 지도 흐름과 스테이지 선택

AI가 "지도 먼저 → 파견 창"과 "파견 창 안에서 지도 열기"를 제안했고, 사용자는 지도 먼저를 골랐다. 사용자는 한 번에 한 스테이지만 진행하고, 스테이지 안의 웨이브는 나중에 던전 단계에 따라 늘리겠다고 했다. 클리어한 단계도 다시 고를 수 있고, 클리어한 스테이지와 다음 스테이지 중에서 고른다고 정했다.

### 지도 그림

처음에는 단계 줄과 스테이지 칸으로 만들었다. 사용자가 손그림 예시를 주어 대륙 위 길·거점 방식으로 바꿨다. 이미지 라이브러리가 없어 AI가 Unity 에디터에서 코드로 대륙 그림(땅, 해안선, 바다, 산, 숲, 나침반)과 거점 아이콘을 그렸다. 길과 거점은 상태별 색을 바꾸려고 그림에 넣지 않고 실행할 때 깔도록 했다.

### ForgeTest 연결

처음에는 `ForgeTest`에도 지도를 연결했다. 사용자 요청으로 씬 변경을 되돌리고, 지도 창이 씬 참조가 연결되었을 때만 등록해 지도부터 열리게 바꿨다. 연결하지 않은 씬은 예전처럼 파견 창부터 연다.

## 주요 결정

- 밤에는 던전 지도 창이 먼저 뜨고, 파견 창에서 지도로 돌아갈 수 있다 (사용자)
- 한 번 파견하면 스테이지 하나만 싸운다. 스테이지 안 웨이브는 나중에 단계에 따라 늘린다 ([미정], 사용자)
- 스테이지를 클리어하면 다음 스테이지가 열리고, 클리어한 스테이지와 다음 스테이지 중에서 고른다. 클리어한 단계도 다시 고를 수 있다 (사용자, 기획 13절 8번 확정)
- 지도는 10단계 전부를 보여 주고 잠긴 단계는 흐리게 둔다 (사용자)
- 다시 이겨도 진행 상황은 늘지 않는다 (AI 제안). 다시 싸운 스테이지도 보상을 받는다는 것은 [추정]으로 둔다
- 지도 아트는 임시이며, 거점 위치는 데이터로 두어 바꾸기 쉽게 한다 (구현 결정)
- `ForgeTest`는 변경하지 않고, 지도는 씬마다 참조를 연결해 붙인다 (사용자)

## AI 활용 범위

AI가 하루 사이클 점검, 규칙·화면 코드 작성, 테스트 갱신을 했다. 지도 그림과 아이콘 생성, 에디터 스크립트로 한 프리팹·씬 구성, 플레이 모드 검증, 문서 갱신도 AI가 했다. 지도 흐름, 한 스테이지 파견, 다시 고르기, 지도 모양(손그림 예시), `ForgeTest`를 건드리지 않는 것은 사용자가 정했다. 커밋과 푸시는 사용자 승인 뒤에 했다.
