- 작업 목적: 방어구 조립 미니게임의 작업대와 화면을 올리고 대장간 방에 연결한다.

## 주요 요청

1. 방어구의 남은 제작 단계(조립)도 작업대에 적용한다.
2. 조립 미니게임 화면 디자인을 다듬고, 맞지 않는 작업대 이름을 고친다.
3. 방 연결도 같은 PR에 넣는다.

## AI와 논의한 내용

### 조립 작업대 구조

- 구조는 판 성형 작업대를 따랐다. 작업대 입력은 상호작용 키(E)와 마우스이고, 입력 잠금은 `PlayerNetworkInputLock`을 쓴다. 미니게임은 실행하는 클라이언트에서만 진행하고 끝나면 정확도만 호스트에 보낸다.
- 방어구 레시피에는 조립 단계가 이미 있어서 레시피는 바꾸지 않았다.
- 판 성형 UI를 복제해 만들었기 때문에 남아 있던 "판 성형 작업대" 문구를 조립 문구("조립 방법", "조립 작업대")로 고쳤다.

### 조립 화면 디자인

- 회색 사각형과 점 대신 가죽 작업 매트 위에 방어구 조각 실루엣을 놓았다(투구: 둥근 몸통·눈 가늠자 구멍 얼굴 가리개·볼가리개, 갑옷: 가슴판 능선·비늘 치마·어깨 돔).
- 덮는 판은 쇠판 모양이고 놓을 자리는 점선 테두리와 구멍 고리로 보여 주며, 구멍이 맞으면 초록으로 바뀐다. 박은 리벳은 반짝이는 머리가 보이고 품질이 좋을수록 초록빛이 돈다. 리벳을 박는 동안 마우스 끝이 망치 모양으로 바뀐다.

### 방 연결과 PR 범위

- 처음에는 공통 틀(`MiniStation` 등)과 조립 작업대를 한 PR에 넣으려 했으나, 조립 작업대는 그 틀을 쓰지 않는 독립 클래스라는 점을 확인했다. 쓰이지 않는 코드가 되므로 공통 틀은 이 PR에서 빼고, 처음 쓰는 활 제작 PR로 옮기기로 했다.
- 사용자의 요청으로 방(`ForgeRoom` 프리팹) 연결을 이 PR에 넣었다. 최신 `dev`의 프리팹에서 조립 칸만 교체했다.
