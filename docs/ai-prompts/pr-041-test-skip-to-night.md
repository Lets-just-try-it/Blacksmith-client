## 개요

- 브랜치: `feat/test-skip-to-night`
- 대상 브랜치: `dev`
- PR: #41
- 작성일: 2026-11-05
- 담당 영역: 시스템·데이터(낮·밤 사이클 테스트 도구)
- 작업 목적: 밤 파견을 테스트할 때 낮 10분을 기다리지 않도록 낮을 바로 끝내는 버튼을 둠

## 주요 요청

1. 테스트 중이니 누르면 바로 밤이 되는 버튼을 하나 추가할 것
2. 버튼 자리에 재화(골드) 표시가 있어 클릭이 안 되니 위치를 조정할 것

## AI와 논의한 내용

### 버튼 동작

낮을 바로 끝내는 테스트용 함수 `GameState.EndDayNow()`가 이미 있었다. 그래서 새 규칙을 만들지 않고 이 함수를 부르는 버튼만 두었다. 낮 시간은 호스트만 바꿀 수 있어서, 버튼은 호스트의 낮에만 보이게 했다. 누르면 기존 규칙대로 밤 전환 연출(3초)을 거쳐 밤이 된다. 미니게임이 진행 중이면 끝날 때까지 기다린다.

### 버튼 위치

시계 프리팹은 고치지 않았다. Game 씬의 시계 오브젝트에 버튼을 붙여 다른 씬에는 생기지 않게 했다. 처음에는 시계 바로 아래에 두었다. 그런데 사용자가 테스트해 보니 그 자리에 골드 표시가 있어 클릭이 되지 않았다. AI가 씬의 UI 배치를 확인한 결과, 골드 표시가 같은 위치에 있었고 그 캔버스가 버튼보다 위에 그려졌다. 버튼을 골드 표시 아래로 옮겼다.

### 클릭이 닿지 않던 다른 원인

옮긴 뒤 버튼 위치로 UI 레이캐스트를 쏴 보니 아무것도 잡히지 않았다. 시계 캔버스에 `GraphicRaycaster`가 없었기 때문이다. 씬의 시계 오브젝트에 이를 붙였고, 그 뒤 버튼이 맨 위로 잡히고 클릭 이벤트로 밤이 되는 것을 확인했다.

### 씬 저장 시 섞인 변경

씬을 저장할 때 대화창 프리팹의 글자 설정이 씬 변경에 저절로 끼어들었다. 이번 작업과 관계없어 걷어냈다.

## 주요 결정

- 낮을 끝내는 방법은 기존 `GameState.EndDayNow()`를 그대로 쓰고, `GameState`는 바꾸지 않는다.
- 버튼은 호스트의 낮에만 보인다.
- 버튼은 Game 씬에만 두고 `DayCycleHud` 프리팹은 고치지 않는다. 위치는 시계와 골드 표시 아래다.
- 테스트용이라 출시 전에 빼야 한다. 진행 문서에 적었다.

## 검증 내용

- 에디터 플레이 모드에서 로비 Host 시작 → Game으로 들어가 확인했다. 버튼 가운데 지점에서 맨 위로 잡히는 UI가 버튼이고, 클릭 이벤트를 보내면 밤 전환 연출을 거쳐 밤이 되며 던전 지도 창이 열렸다.
- 밤에는 버튼이 숨고 다음 날 낮에 다시 보였다. 콘솔 오류는 없었다.
- 실제 마우스 클릭과 두 명 접속은 확인하지 않았다.

## AI 활용 범위

AI가 기존 낮·밤 코드와 씬 UI 배치를 확인하고, 버튼 스크립트 작성, Unity CLI로 씬 배치와 플레이 모드 검증, 진행 문서 수정을 했다. 사용자는 버튼 추가를 요청했고, 직접 테스트해 골드 표시와 겹쳐 클릭이 안 되는 문제를 찾아 위치 조정을 요청했다. 커밋과 PR 내용도 확인해 승인했다.
