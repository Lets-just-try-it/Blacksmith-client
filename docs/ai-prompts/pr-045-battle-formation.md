- 작업 목적: 전투에서 모험가가 진행 방향을 보게 하고, 직업별 사거리와 근접 앞·원거리 뒤 대열을 만든다.

## 주요 요청

1. 전투 씬에서 모험가가 앞을 보지 않는다. 진행 방향을 보게 바꾼다.
2. 모험가 직업별로 사거리를 조정한다.
3. 전투를 시작할 때 근접은 앞, 원거리는 뒤에 배치한다.
4. 한 줄로 세우지 말고 상황에 맞게 두 줄로 세운다.
5. 한 줄은 최대 3명이다. 5명 파티에서 근접 4·원거리 1은 2/2/1, 근접 1·원거리 4는 1/2/2, 근접 3·원거리 2는 3/2, 근접 2·원거리 3은 2/3으로 선다. 원거리 3명을 2/1로 나누지 않는다.
6. 5명 대열을 플레이 모드로 먼저 확인한다.

## AI와 논의한 내용

### 모험가가 옆을 보는 원인

`BattlePlayer`가 유닛을 회전 없이 생성하는데, 인간형 모델의 정면은 +Z이고 전투 진행 축은 +X였다. 모험가만 진행 방향을 보도록 생성할 때 돌리기로 했다. 몬스터 임시 모델은 둥근 캡슐이라 방향이 드러나지 않아 그대로 두었다.

### 직업별 사거리

전투 코드는 이미 직업별 사거리를 받고 있었지만 세 직업 모두 120이었다. 몬스터 궁수(450)·주술사(400)와 같은 수준의 안을 제시했고, 사용자가 전사 120, 궁수 450, 마법사 400을 골랐다.

### 대열 규칙

처음에는 사거리 순으로 한 줄씩 세웠다가, 사용자 요청으로 두 줄로 바꿨다. 근접·원거리를 나누는 방법으로 사거리 기준값, 항상 반으로 나누기, 줄당 최대 인원을 비교했고, 사용자가 사거리 기준값(근접 앞줄, 원거리 뒷줄)을 골랐다. 이어서 사용자가 한 줄 최대 3명과 5명 파티의 대열(2/2/1, 1/2/2, 3/2, 2/3)을 정했다. 처음 구현은 3명을 먼저 채워(1/3/1) 사용자 예시와 달라, 넘는 종류를 고르게 나누도록(4명 → 2/2) 고쳤다.

### 5명 대열 확인 방법

테스트 씬의 파티는 시드로 생성되어, 시드와 인원을 잠시 바꿔 각 조합을 플레이 모드에서 확인했다. 전사 4명이 나오는 시드가 없어, 2/2/1은 근접 기준을 잠시 올려 마법사를 앞줄로 세워 같은 배치 계산을 확인했다. 씬과 데이터는 저장하지 않고 원래대로 되돌렸다.

## 주요 결정

- 모험가만 진행 방향을 보도록 생성한다.
- 직업별 사거리: 전사 120, 궁수 450, 마법사 400 [추정] (사용자 결정).
- 사거리 200 이하를 근접으로 본다 [추정]. 근접은 앞줄, 원거리는 뒷줄에 선다 (사용자 결정).
- 한 줄 최대 3명 [추정]. 넘는 종류는 그 종류끼리 고르게 나누고, 3명 이하는 나누지 않는다 (사용자 결정).
- 근접 기준과 한 줄 최대 인원은 `BattleRules` 데이터에 둔다.
- 유닛 번호와 결과 순서는 파티 순서 그대로 두고 시작 위치만 바꾼다.
