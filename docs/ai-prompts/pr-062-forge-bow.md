## 주요 요청

1. 활 작업대를 추가한다. 활이 단조·담금질을 거치는 것은 이상하니 활의 실제 제작 과정에 맞춰 단계와 미니게임을 다시 생각한다(참나무, 주괴, 끈 등 재료가 기획 문서에 있으면 그대로 따른다).
2. 미니게임은 대중적으로 알려진 게임을 활 제작에 어울리게 입히고, 다른 제작 단계와 겹치지 않게 한다.
3. 활 깎기는 톱질로 하고, 3D로 만들며, 소리가 톱질 느낌을 살려야 한다. 마지막에는 나무 소리 위주로 바꾼다.
4. 몸체를 쇠(광석)로 만드는 방식을 검토하고, 몸체 휘기를 단순한 클릭 유지보다 조작과 판단이 있는 방식으로 만든다.
5. 시위 걸기 단계를 추가하고, 매듭을 짓는 과정과 힘줄이 몸대에 감기는 장면이 화면에 보이게 한다. 연결 부분은 단순 클릭이 아닌 방식으로 다시 만든다.
6. 시험 사격은 양궁 게임처럼 진짜 활을 쏘는 느낌으로 만든다. 대장간 안의 작은 사격실, 볏짚 허수아비, 45초 동안 계속 진행, 머리 명중은 2점(치명타 연출)으로 한다.
7. 각 작업대를 바로 테스트할 수 있도록 재료를 기본 지급한다(작업 중인 중간 재료는 제외, 주괴는 포함).
8. 대장간을 작업 순서대로 재배치한다.

## AI와 논의한 내용

### 활의 제작 단계

- 처음에는 활도 대검처럼 단조·담금질을 거치게 했으나, 사용자가 활이 쇠를 두드려 만드는 것은 이상하다고 지적해 활 전용 단계로 다시 정했다.
- 처음에는 참나무 활 몸체를 깎고 주괴로 보강쇠를 다는 구성이었으나, 보강쇠 단계가 활 미니게임과 어울리지 않는다는 지적으로 없앴다.
- 사용자가 "몸체를 광석으로 한다면?"을 물어 실제 활과 판타지 게임의 활을 비교했다. 순수 금속 활은 드물고, 몸체는 쇠이고 나무로 손잡이와 심을 붙이는 복합궁으로 정했다. 광석 등급이 활 성능을 정한다.
- 최종 흐름은 정제 → 활 몸체 휘기 → 활 깎기 → 시위 걸기 → 시험 사격의 5단계이다. 정제는 기존 단계이고, 이번 PR에서 나머지 4단계의 미니게임을 새로 만들었다. 지팡이는 이번 범위에서 제외했다.

### 활 깎기(톱질)

- 검으로 베는 방식, 못 박기(두더지 잡기), 나무 깎기 균형, 톱질 박자와 선 유지는 사용자가 "무슨 게임인지 모르겠다", "활에 어울리지 않는다"고 해서 버렸다. 베기 미니게임 코드는 대검 시험 후보로만 남기고 이 PR에는 넣지 않았다.
- 최종안은 마우스 버튼을 누른 채 위아래로 움직여 톱질하고, 제한시간 안에 통나무를 최대한 많이 켜는 방식이다. 힘의 세기는 게이지 대신 톱밥·톱날 색·불똥·톱 소리로 보여 주고, 마우스는 화면 어디서 시작해도 된다.
- 3D 장면(모탕 위 통나무, 톱, 켜진 틈, 갈라져 떨어지는 통나무)으로 바꾸었다. 톱 소리는 쇠 긁는 소리가 듣기 싫다는 지적으로 나무 소리 위주로 다시 만들었다.

### 활 몸체 휘기

- 단순히 누르고 있는 방식이 밋밋하다는 지적으로, 마디를 눌러 아래로 끌어 내리면 휘고 놓으면 탄성으로 되돌아오는 방식으로 바꾸었다.
- 마디마다 열이 식어 E로 다시 달구는 판단 요소를 넣었다. 식으면 같은 거리를 끌어도 덜 휘고 더 되돌아온다.

### 시위 걸기

- 힘줄을 감는 것까지는 좋다는 평가를 받았고, 연결 부분이 단순한 타이밍이라는 지적으로 "활을 휘면서 고리를 미는 두 손 작업"으로 바꾸었다. 마우스를 아래로 끌어 휘고, 휘기가 알맞은 구간일 때 옆으로 끌어 고리를 활 끝으로 민다.
- 힘줄이 몸대에 감기는 모습이 잘 보이도록 카메라를 활 끝으로 가까이 가져가고 감은 띠가 몸대 둘레에 쌓이게 했다.

### 시험 사격

- 처음의 2D 화면에서 일인칭 3D로 바꾸고, 숨 참기, 바람, 낙차, 화살 포물선, 박히는 소리와 점수 연출을 넣었다.
- 배경은 야외에서 대장간 안의 작은 사격실로, 과녁은 고리 과녁에서 볏짚 허수아비로 바꾸었다. 크기를 사람 키 정도에서 훨씬 작게 줄이고, 머리는 맞추기 어렵게 했다.
- 목표 점수를 채워도 끝나지 않고 45초 동안 계속 진행하도록 했다(목표 점수 12 / 16 / 20점, 점수는 계속 쌓이고 정확도는 만점에서 멈춘다).

## 주요 결정

- 활 레시피는 주괴 4개 + 참나무 목재 1개 + 힘줄 2개이고 구리·철 두 종류다.
- 각 미니게임의 규칙은 `Core/Forge`에 시드를 받는 순수 C#으로 두고, 수치는 ScriptableObject 데이터에 둔다(모두 임시 수치).
- 작업대가 같이 쓰는 공통 틀(`MiniStation`, `MiniPanelView`, `MiniBoardView`, `MiniStage`, `PixelShapes`)을 만들어 활 작업대 4개가 쓴다.
- 공용 창고 시험 지급은 광석, 주괴, 참나무 목재, 힘줄, 보석만 두고 작업 중인 중간 형태 아이템은 뺀다.
- 대장간은 34m × 26m로 넓혀 작업 순서대로 배치한다(뒷줄: 휘기 → 깎기 → 시위 걸기 → 시험 사격).
- `docs/GAME_CONCEPT.md`에 활 단계 절과 재료, 작업대 배치를 `[추정]`으로 정리했다. 병합 전에 팀에 공유가 필요하다.

## AI 활용 범위

AI가 활 제작 단계 비교와 제안, 미니게임 규칙·화면·3D 장면·효과음 구현, 레시피와 아이템 데이터, 대장간 재배치, 테스트, 문서 정리를 수행했다. 활 제작 단계와 각 미니게임의 방향(쇠 몸체 복합궁, 톱질, 두 손 걸기, 허수아비와 치명타 등), 마음에 들지 않는 안을 버리는 결정, 실제 플레이 확인은 사용자가 했다.
