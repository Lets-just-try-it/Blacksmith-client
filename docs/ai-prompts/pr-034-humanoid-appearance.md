- 작업 목적: Blender에서 만든 인간형 모델을 플레이어·영입 후보·손님·전투 모험가에 붙이고, 외형 생성을 공용 구조로 바꾸며, Blender와 같은 팔레트 툰 셰이딩을 재현함

## 주요 요청

1. Blender 익스포트(Hero_v2)를 기반으로 플레이어, 영입할 모험가, 자동 전투 유닛, 손님 모두에게 인간형 모델을 붙일 것
2. 외형 기능은 모험가 전용이 아니므로, 모험가 이름이 붙은 스크립트를 고치거나 새로 나눠 공용으로 만들 것. 기존에 모험가 외형 코드를 쓰던 곳도 함께 고칠 것
3. 눈·입·헤어 등은 계속 늘어나므로 개수를 코드에 박지 말고 필요하면 ScriptableObject를 쓸 것
4. 영입 후보는 투구·갑옷 칸이 비고 기본무기만 든 채로 생성된다는 새 기획을 문서에 추가할 것
5. 머티리얼을 Blender와 같은 팔레트 기반 툰 셰이딩으로 만들고 Unity 조명에 따라 어두워지게 할 것
6. Blender 익스포트가 바뀔 때마다(대기 동작 수정, 팔레트·UV 재정리, 부드러운 노멀, 신발 노멀 수정) 다시 적용할 것

## AI와 논의한 내용

### 공용 외형 구조

AI는 모험가 외형 타입과 생성 데이터를 공용 `HumanoidAppearance`와 외형 목록 데이터(`HumanoidLookData`)로 나누는 안을 냈다. 개수는 목록 길이로 정하고, 번호가 목록 위치이므로 끝에만 추가하는 규칙을 두었다. 모험가 생성과 손님 생성이 같은 생성 함수를 쓴다.

### 모자와 헤어, 장비 모델

모델의 헬멧·캡·헤어밴드 이름이 쓰는 곳을 나누는 것인지 확인했다. 사용자는 투구 칸에 모두 들어가고, 이름은 모자 종류마다 다른 헤어 버전을 고르기 위한 것이라고 정했다. 그래서 모자 데이터에 쓸 헤어 버전과 귀 숨김 여부를 두었다.

### 기본무기와 장비 교체

사용자는 다음을 정했다.
- 모험가는 기본무기를 항상 들고, 장비는 벗길 수 없고 교체만 한다.
- 기본무기는 새 아이템(낡은 대검·활·지팡이, 무기 A 모델)으로 하고, 무기 B 모델은 상위 장비로 쓴다.
- 교체한 장비는 부위와 상관없이 사라진다. 다만 공용 창고로 돌려보내는 코드는 지우지 말고 남긴다.
- 벗기기 기능 제거는 문서에만 적고 별도 작업으로 한다.

### 머티리얼과 셰이더

1. 처음에는 Simple Lit 단색으로 시작했다.
2. 사용자가 Unlit을 제안했고, AI가 대안을 보여 준 뒤 사용자가 Shader Graph로 만드는 단색 툰 셰이더를 골랐다.
3. 이후 Blender 쪽이 팔레트 램프 구조(텍스처 한 장, UV가 색 행을 가리킴)로 바뀌어, 그 사양대로 다시 만들었다.
4. Blender 사양은 조명을 곱하지 않지만, 사용자 요청에 따라 해·환경광 세기를 곱해 밤에 어두워지게 했다.
5. 피부색·머리색은 사양의 렌더러별 행 교체를 그대로 쓰되, 줄 번호를 데이터로 받아 셰이더를 고치지 않고 늘릴 수 있게 했다.
6. 머리색 처리 방안 세 가지(Blender 팔레트에 추가, Unity 팔레트만 수정, 틴트)를 보여 주었고, 사용자는 Blender에서 직접 색을 추가했다.

### 받는 그림자와 모서리 경계

- 얼굴에 생기는 계단 모양 그림자 경계에 대해 AI가 원인(그림자 맵 해상도, 단계 경계)과 세 가지 안을 설명했다. 사용자는 지금 상태로 두기로 했다.
- 면 사이 명암 경계에 대해서는 사용자가 Blender에서 부드러운 노멀(60° 기준)로 다시 익스포트했다.

### 파츠를 한 모델에 넣어 두는 방식

사용자가 모든 의상 파츠를 미리 넣어 두는 이유를 물었다. AI는 다음을 설명했다.
- 스킨드 의상을 따로 떼려면 뼈 재연결, 파츠별 익스포트, 생성·정리 코드가 필요하다.
- 지금 규모에서는 켜고 끄는 방식이 가장 단순하다.
- 바꿀 때는 `HumanoidAppearanceView` 안만 고치면 된다.

사용자는 지금 방식을 유지하기로 했다.

전투 모험가가 옆을 보는 원인(회전 없이 생성)을 찾았다. 사용자는 전투 담당자가 고치도록 진행 문서에 기록만 하기로 했다.

## 주요 결정

- 플레이어 외형은 고정(의상 B)이고 커스터마이즈는 [고도화]다.
- 외형에 의상을 추가하고, 모험가는 의상 A, 손님은 모든 의상에서 고른다.

- 모험가는 직업 기본무기를 든 채로 생성되고 투구·갑옷·장신구 칸은 비어 있다. [추정] 기본무기 공격력 +5.
- 장비는 교체만 가능하고 교체한 장비는 사라진다. 공용 창고 반환은 설정으로 남기고 기본은 끈다.
- 머리색 6종·피부색 4종을 팔레트 행으로 정했다(기존 [추정] 6종·5종을 정리).
- 셰이더는 Shader Graph 팔레트 램프 툰이고, 조명 세기를 곱해 밤에 어두워진다. 받는 그림자는 지금 상태로 둔다.
- 전투 방향 문제는 전투 담당 작업으로 남긴다.
- `docs/GAME_CONCEPT.md` 5.3, 6.2, 7.1절을 바꿨다(기획 변경, 팀 공유 필요).

## AI 활용 범위

AI가 한 일:
- 공용 외형 구조와 기본무기 설계안 제시, 코드·테스트 작성
- Unity CLI로 모델·애니메이션 임포트, 애니메이터·프리팹·데이터 구성, Shader Graph 생성

사용자가 한 일:
- 플레이어 외형 고정, 의상 추가, 모자·헤어 규칙, 기본무기·장비 교체 규칙, 셰이더 방식, 그림자 처리 유지, 전투 방향 문제 기록만 하기를 결정
- Blender에서 모델·애니메이션·팔레트·노멀을 고쳐 다시 익스포트
- 에디터에서 모습을 직접 확인하고 문제를 찾아 알려 줌
