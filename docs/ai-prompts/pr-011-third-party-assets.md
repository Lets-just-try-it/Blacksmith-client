## 주요 요청

1. 담금질 화면에 쓸 추천 에셋을 찾아 줄 것
2. 무료 에셋으로 먼저 진행할 것
3. 임포트가 필요한 에셋 목록을 정리할 것
4. 외부 에셋은 `Assets/ThirdParty`에 둘 것

## AI와 논의한 내용

### 추천 에셋 검색

AI가 대장간 소품, 불꽃·김·물튀김 이펙트, 효과음 후보를 웹 검색으로 찾아 용도별로 정리했다. 확인한 무료 후보는 Unity Asset Store의 대장간 소품 세트 하나, itch.io의 불꽃 셰이더, CC0 모루 효과음이었다. 달군 쇠를 물에 담글 때 나는 소리는 라이선스가 확실한 무료 에셋을 찾지 못했다. 가격과 호환성은 검색 결과 기준이라 구매 전에 확인하도록 안내했다. 아트 방향이 정해지기 전에 유료 에셋을 사면 통일감이 깨질 수 있다고 설명했다.

### 임포트 방식과 폴더

Asset Store 에셋은 Unity 계정으로만 받을 수 있어서 AI가 직접 내려받지 못한다고 설명했고, 사용자가 임포트했다. 외부 에셋 폴더 규칙이 없어서 사용자에게 선택지를 주었고 `Assets/ThirdParty`로 정했다. 임포트한 에셋은 탐색기가 아니라 Unity Project 창에서 옮기도록 안내했다.

### 머티리얼 변환

임포트한 소품 머티리얼이 URP가 아닌 기본(Standard) 셰이더라서 그대로 쓰면 분홍색으로 깨진다. AI가 2개를 URP Lit로 바꾸고, 임시 장면에서 소품 10종을 배치해 정상 표시를 확인했다. 확인용 장면은 저장하지 않고 닫았다. 소품 크기가 제각각이라는 점도 이때 확인해 README에 적었다.

### PR 분리

이 작업은 담금질 PR과 분리했다. 임포트한 소품을 담금질 화면에 적용하는 일은 담금질 PR에만 있는 프리팹을 바꾸기 때문에, 두 PR이 병합된 뒤에 따로 한다.

## 주요 결정

- 외부 에셋은 `Assets/ThirdParty`에 두고 패키지마다 폴더를 나눈다. `CLAUDE.md` 폴더 구조에 반영한다. (사용자 결정)
- 무료 에셋으로 먼저 진행하고 유료 에셋은 아트 방향이 정해진 뒤에 검토한다. (사용자 결정)
- 출처, 라이선스, 수정 사항은 `Assets/ThirdParty/README.md`에 기록한다. (AI 제안, 사용자 승인)
- 소품 머티리얼은 URP Lit로 변환한다. (AI 제안, 사용자 승인)
- 이번 PR은 임포트와 정리만 하고 장면에는 쓰지 않는다. (AI 제안, 사용자 승인)
- 폴더 구조 변경은 기획 변경이 아닌 프로젝트 규칙 변경이며 팀 공유가 필요하다.

## AI 활용 범위

AI가 에셋 검색과 정리, 머티리얼 URP 변환, 표시 확인, README와 문서 작성을 맡았다. 사용자는 사용할 에셋 범위, 폴더 위치, 에셋 임포트와 Unity 이동 작업을 직접 했다. 커밋과 PR 내용은 AI가 초안을 보이고 사용자가 승인했다. 폴더 구조 변경의 팀 공유는 사용자가 직접 한다.
