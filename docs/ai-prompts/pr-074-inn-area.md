## 주요 요청

1. 광장에서 들어가는 여관 구역을 만들고, 관리 중인 모험가가 여관 안에 머물며 돌아다니게 한다.
2. 모험가를 파견하면 전투 화면에 여관이 겹쳐 보이는 문제를 고친다.

## AI와 논의한 내용

### 여관 구성

여관은 광장 건물에서 포털로 들어가는 별도 구역으로 하고, 홀과 방 4개, 침대 8개(관리 슬롯 최대 수)로 구성했다. 모험가는 침대마다 하나씩 스폰하고, 이어 둔 지점을 따라 걷게 했다.

### 전투 화면에 여관이 겹쳐 보이는 문제

사용자가 Additive로 불러오는 씬인데 왜 겹쳐 보이는지 물었다. AI는 이렇게 설명했다.
- Additive 씬도 같은 월드 좌표에 함께 놓이고, 카메라는 불러온 모든 씬의 오브젝트를 그린다.
- 전투 중에는 낮 씬의 카메라·UI·조명만 꺼지고 오브젝트는 남는다.
- 그래서 구역을 좌표로 나눠 왔는데(광장 x = 500, 전투 x = 1000, 채집 맵 x = 2000), 여관을 전투 공간과 같은 x = 1000에 둔 것이 원인이다.

## 주요 결정

- 여관은 광장의 건물이고, 문에 닿으면 안으로 들어간다. (기획 확정)
- 내부는 1층 홀(카운터, 벽난로, 탁자)과 침대 2개씩 있는 방 4개, 침대 8개다. (기획 확정)
- 영입한 모험가는 자기 침대를 받아 홀과 자기 방을 돌아다니고, 사망하면 사라진다. (기획 확정)
- 여관을 x = 3000으로 옮긴다. 전투 공간을 옮기지 않고 새로 추가된 여관을 비어 있는 좌표로 옮겼다. (AI 제안, 사용자 승인)
