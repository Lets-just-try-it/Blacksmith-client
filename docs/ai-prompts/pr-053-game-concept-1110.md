## 주요 요청

1. 노션 "11월 10일 Game Concept 정리"의 수정안을 기획 문서 전체에 반영한다. 임베드 이미지는 읽지 않는다.
2. "A에서 B로 바뀌었다"가 아니라 바뀐 내용만으로 일관된 문서로 다시 쓴다.
3. MVP는 이미 구현되었으므로 MVP 언급을 빼고, 새로 넣은 시스템은 데모 1을 위해 필요한 기능으로 정리한다.

## AI와 논의한 내용

### 노션 수정안에서 모호한 항목

수정안만으로 정할 수 없는 네 가지를 사용자에게 물었다.

### MVP 범위 표기

MVP 범위 절을 데모 1 범위로 바꾸고, 이미 구현된 기능은 목록에서 빼고 새 기능만 남겼다. "삭제" 목록은 바뀐 이력이라 지웠다.

## 주요 결정

- 사용자 결정: 가방으로 개인 인벤토리를 8 → 16 → 24칸으로 늘린다.
- 사용자 결정: 1티어 광석 이름은 청동이다.
- 사용자 결정: 부상은 부상수치로 나타내고, 세부는 [미정]으로 둔다.
- 사용자 결정: 기본 채집 도구(곡괭이, 도끼, 갈무리칼)를 처음부터 준다.
- 사용자 결정: MVP 언급을 빼고 12절을 데모 1 범위로 둔다.
- 문서 정리 중 정한 것:
  - 장비 등급은 정제 다음 단계 점수로만 정한다. 연마의 처음 날 상태는 단조·담금질 평균을 쓴다.
  - 레시피는 주괴 단위로 적는다.
  - 데모 1 던전은 2단계까지다.
- [추정]으로 둔 것:
  - 여관에서 꾸린 파티가 밤 파견 창에 그대로 올라온다.
  - 채집하는 동안 몬스터가 나오지 않는다.
  - 보스는 잡몹 무리를 모두 토벌한 뒤 나타난다.
  - 녹이면 주괴 × 남은 내구도 비율만큼 돌려받는다.
- [미정]으로 둔 것: 던전 이동 방법, 정제할 때 넣는 광석 수와 나오는 주괴 수, 의뢰 보상, 상점 가격, 새 시스템 담당자 등. 모두 15절에 모았다.
