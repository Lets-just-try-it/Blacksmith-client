## 주요 요청

1. 방어구 판 성형 미니게임이 렉이 너무 심해서 해결한다.

## AI와 논의한 내용

### 렉 원인

- 판 성형의 쇠판 화면(`PlateBoardView`)이 매 프레임 1432×904 픽셀 텍스처 전체를 다시 그렸다.
- 바탕, 쇠판 결 20줄, 리벳, 굵은 허용 띠, 점선을 모두 CPU로 그린 뒤 5MB를 올려서, 에디터 기준 한 번에 약 275ms(난이도 0), 초당 4프레임 정도였다.

### 고친 방법

- 바뀌지 않는 바탕(쇠판, 허용 띠, 점선)은 조각이 바뀔 때만 한 번 그려 저장하고, 매 프레임은 복사로 되돌리게 했다. `PixelCanvas`에 `SaveSnapshot()`과 `RestoreSnapshot()`을 추가했다.
- 매 프레임 그리는 것은 오린 자국, 길 안내 화살표, 녹색 점, 마우스 커서뿐이다.
- 밑그림 점선을 처음부터 끝까지 그려 두되 오린 자국이 위를 덮으므로 화면 결과는 같다.

## 주요 결정

- 이번에는 요청받은 판 성형만 고쳤다. 정제, 연마 같은 다른 미니게임도 같은 캔버스를 쓰므로 비슷한 렉이 있으면 같은 방법을 적용할 수 있다.

## 검증 내용

- 에디터에서 `Tick` 시간만 재서 같은 화면을 그리는 시간이 약 3~6ms로 줄어든 것을 확인했다(난이도 0과 2, 오리기 시작 전과 중간 모두).
- 그려진 모습이 그대로인 것을 확인했다.
- 사용자가 실제 플레이에서 렉이 사라진 것을 직접 확인했다.

## AI 활용 범위

AI가 렉 원인 측정과 수정, 화면 확인을 수행했다. 렉을 고칠 대상(판 성형)과 별도 PR로 나누는 방침은 사용자가 정했고, 수정 후 실제 플레이에서 렉이 사라졌는지는 사용자가 직접 확인했다.
