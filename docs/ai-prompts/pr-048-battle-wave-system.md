## 개요

- 대상 브랜치: `dev`
- PR: #48

- 작업 목적: 한 번 파견에 스테이지 하나를 싸우는 구조에서, 한 스테이지 안에 여러 번의 전투(웨이브)를 넣고 몹 수·웨이브 수로 드랍을 조정한다.

## 주요 요청

1. 전투를 웨이브 시스템으로 바꾼다. 난이도에 따라 몹 수와 웨이브 수를 정한다.
2. 보스 스테이지에서도 몹 웨이브를 몇 차례 이긴 뒤 보스 웨이브를 싸운다.
3. 몹 수와 웨이브 수로 아이템 드랍률을 조정한다.
4. 웨이브마다 몹 수가 달라도 된다. 1단계 1스테이지는 1웨이브 1마리, 2웨이브 2마리로 한다.

## AI와 논의한 내용

### 난이도 기준과 웨이브 구성

AI가 난이도 기준(던전 단계 + 스테이지 / 단계만 / 별도 난이도 선택)과 몹 구성 방식(몹 풀에서 시드로 뽑기 / 웨이브별 직접 배치)을 선택지로 제시했다. 사용자는 던전 단계 + 스테이지 기준과 몹 풀 시드 뽑기를 골랐다.

### 드랍과 패배 보상

드랍을 몬스터마다 굴릴지 스테이지 보상에 배율을 곱할지 논의했고, 사용자는 몬스터마다 굴리기를 골랐다. 패배 시에는 클리어한 웨이브까지 보상을 받는 쪽으로 정했다. AI는 골드·경험치도 몬스터 한 마리 몫으로 두어 몹 수에 따라 함께 늘도록 구현했다.

### 시작 수치

AI가 웨이브 전 스테이지 보상을 몹 수로 나눠 한 마리 몫을 정하고 웨이브 구성을 제안했다. 사용자는 웨이브마다 몹 수가 달라도 된다고 했고, 1단계 1스테이지 구성을 직접 정했다.

## 주요 결정

- 웨이브 수와 웨이브별 몹 수는 던전 단계와 스테이지가 정하고, 웨이브마다 몹 수가 다를 수 있다 (사용자)
- 웨이브 몹은 스테이지의 몹 풀에서 전투 시드로 뽑는다 (사용자)
- 드랍은 쓰러뜨린 몬스터마다 굴린다 (사용자)
- 패배하면 클리어한 웨이브까지 보상을 받고, 스테이지 진행은 모든 웨이브를 이겨야 오른다 (사용자)
- 1단계 1스테이지는 1마리 → 2마리 (사용자)
- 나머지 웨이브 구성과 몬스터별 보상 수치는 [추정]으로 두고 데이터로 뺐다 (구현)
- 시뮬레이션 안의 스테이지 이름을 웨이브로 바꿨다 (구현)
