## 주요 요청

1. 던전 데이터와 지도 창을 5단계 구성으로 바꾸고, 확률 드랍과 장신구 효과를 반영한다(전투 담당 남은 작업).
2. 2단계 몬스터는 기존 고블린과 오크에서 적절히 나누어 고른다(고블린과 오크가 크게 다르지 않다고 보고 한 단계로 묶음).
3. 전투 중 드랍되어 실제로 얻는 아이템은 몬스터가 쓰러질 때 바닥에 떨어지는 모습으로 보여 준다.
4. 보스가 죽고 스테이지가 끝나도 쓰러진 모습이 안 보이고 이펙트가 계속 나오는 문제를 함께 처리한다.

## AI와 논의한 내용

### 보스가 쓰러지지 않는 문제

BattleTest에서 재현해 보니, 이긴 경우에는 보스가 눕고 오라도 멈췄다. 사용자가 본 장면은 모험가가 모두 쓰러져 진 경우로, 보스가 살아 있어 오라가 계속 나오는 것이 맞는 동작이었다(사용자도 같은 판단). 다만 결과창이 마지막 몬스터가 쓰러지는 틱에 바로 떠서 쓰러지는 모습과 드랍을 가리는 것을 찾아, 결과창을 1.5초 늦게 띄우기로 했다.

### 목걸이 아이템이 없는 문제

장신구 효과를 붙일 목걸이 아이템이 없었다. 아이템을 만들지 않고 전투 쪽 표만 두는 방법과, 인벤토리 영역의 아이템 데이터에 목걸이 12종을 추가하는 방법을 비교했다. 사용자가 12종 추가를 골랐다.

### 2단계 몬스터 구성

고블린 셋(근접·원거리·회복)을 잡몹으로, 오크를 강한 쪽(광전사, 보스 대족장)으로 나눴다. 단계 순서가 이전 구성과 바뀌어서, 몬스터 수치를 역할별로 옮겨 "1단계 1스테이지는 기본무기 1명 클리어" 기준을 지켰다.

### 드랍 연출 방식

드랍은 기획대로 스테이지 단위로 굴리고, 그 스테이지 몬스터들에게 나눠 쓰러질 때 떨어뜨린다. 마지막에 쓰러지는 몬스터(보스)가 먼저 받는다. 결과를 미리 계산해 이긴 스테이지의 재료만 보여 준다. 에메랄드 효과는 합계에 올림으로 적용하고, 늘어난 몫은 마지막으로 클리어한 스테이지 드랍에 더해 보여 준다.

## 주요 결정

- 사용자 결정: 목걸이 아이템 12종(보석 4종 × 티어 3)을 아이템 데이터에 추가한다.
- 사용자 결정: 2단계 몬스터는 고블린과 오크에서 나누어 고른다(구체 구성은 AI에 맡김).
- 사용자 확인: 보스가 쓰러지지 않아 보인 것은 패배한 경우였다.
- 구현 결정: 2단계는 고블린 전사·궁수·주술사 + 오크 광전사, 보스 오크 대족장(분노 60%). `GAME_CONCEPT.md`의 [미정] 해소
- 구현 결정: 결과창을 전투 종료 1.5초 뒤에 띄운다([추정]).
- 구현 결정: 장신구 보너스는 올림, 2티어 1.5배가 소수면 버린다.
- 구현 결정: 지도 15거점은 기존 30거점 길에서 고르게 골라 쓴다.
