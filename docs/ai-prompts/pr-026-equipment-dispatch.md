## 주요 요청

1. 드래그 앤 드롭으로 옮길 때 허용된 칸에만 옮길 수 있게 할 것
2. 파견 창에서 장비를 입힐 때 공용 장비 인벤토리(공용 창고와 모든 플레이어 개인 슬롯의 장비, 재료·제작 과정물 제외)를 띄울 것
3. 무기 칸에 방어구를 넣으면 입력되지 않고 장비는 원래 자리로 돌아갈 것
4. 직업별로 착용할 수 있는 무기 종류가 다를 것. 처음에는 탱커·방패도 있었으나 작업 중 삭제를 요청했다
5. 이후 요청
   - 창을 넓힐 것
   - 장비 칸 왼쪽에 모험가 모습을 보여 줄 것
   - 장비 칸을 투구·갑옷·무기 순으로 둘 것
   - 장비를 입혔을 때의 능력치 변화를 보여 줄 것
   - 부위별 필터와 장신구 칸을 추가할 것
   - 창이 열리면 하단 개인 슬롯을 숨길 것
6. "무기: 대검만 착용" 문구를 지우고, 맞지 않는 무기를 놓으면 토스트로 띄웠다 지울 것
7. 커밋을 성격별로 나눠 올릴 것

## AI와 논의한 내용

### 파견 창이 없는 상태

파견 창은 아직 없고 전투·광장 담당 작업이었다. AI가 범위를 물었고, 사용자는 인벤토리 영역에 장비 착용 창만 만들고 파견 창이 나중에 띄우는 방식을 골랐다.

### "허용된 칸"의 뜻

AI가 일반 인벤토리 칸 제한인지 장비 칸 규칙인지 물었다. 사용자는 장비 칸 규칙(부위, 직업별 무기 종류)으로 정했다.

### 장비 보정

장비가 능력치에 주는 보정은 기획 6.4절에서 [미정]이었다. 변화량을 보여 주려면 공식이 필요해 AI가 두 가지를 물었다.
- 공식: 사용자는 "아이템별 기본 보정 × 등급 배수"를 [추정]으로 고르고 전투에도 적용하기로 했다.
- 전투 적용: 화면 예측과 실제 계산이 같은 함수를 쓰는 원칙에 따라 전투에도 같은 계산을 쓴다.

### 모험가 모습

초상은 임시 이미지 하나뿐이었다. 사용자는 직업의 전투 모델을 별도 카메라로 찍는 3D 미리보기를 골랐다.

### 새 직업과 전투 데이터

새 직업을 생성 데이터에 등록하면, 전투 수치가 없을 때 영입된 모험가를 전투에 보내는 순간 오류가 난다. 그래서 AI가 전사 항목을 복사해 전투 데이터에도 넣었다.

### 커밋 나누기

AI가 의존 순서대로 다섯 개로 나누는 안을 제안했고 사용자가 승인했다.
- 인벤토리 화면 정리
- Core 규칙
- 광장·전투 데이터
- 장비 창
- 문서

## 주요 결정

- 장비 착용 창만 인벤토리 영역에 만든다. 파견 창은 전투·광장이 만든다.
- 입힌 장비는 인벤토리에서 빠져 모험가에게 등급과 함께 저장된다. 벗기거나 바꾸면 공용 창고로 돌아간다.
- 무기 칸 규칙
  - 전사는 대검, 궁수는 활, 마법사는 지팡이만 착용한다.
  - 투구·갑옷·장신구는 직업 제한이 없다.
  - 탱커와 방패는 사용자 요청으로 삭제했다.
- 장신구는 필터 탭과 모험가 장비 칸까지 넣는다. 장신구 아이템은 아직 없다.
- 장비 보정 = 아이템 기본 보정 × 등급 배수([추정], 데이터로 둠). 장비 창과 전투가 같은 계산을 쓴다.
- 맞지 않는 장비를 놓으면 토스트로 이유를 띄우고, 직업별 무기 종류는 창에 적지 않는다.
- 장비 선택은 기획 8절에 따라 호스트만 한다.

## AI 활용 범위

- 기존 광장·전투·인벤토리 코드 조사
