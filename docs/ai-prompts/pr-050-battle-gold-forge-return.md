## 주요 요청

1. 전투에서 돈이 나오지 않게 바꾼 것 같은데 현재 상태를 확인한다.
2. 전투 결과 화면이 끝나면 페이드 아웃 → 페이드 인으로 대장간 화면이 보이게 한다.
3. 결과창에는 골드를 보여 주고, 전투 중 오른쪽에 뜨는 골드 표시는 없앤다.

## AI와 논의한 내용

### 전투 골드의 현재 상태

PR #44는 결과창에서 골드 표시만 뺐고, 골드는 계속 공용 골드에 들어가고 있었다. 전투 중 보이던 "0 G"는 전투 UI가 아니라 낮 씬 골드 표시(`ShopHud`)였다. `DaySceneBattleCover`의 캔버스 목록에서 빠져 전투 씬 위에 남아 있었다.

### 결과 후 대장간 복귀

결과창 뒤의 페이드 아웃 → 페이드 인은 이미 있었고, 빠진 것은 플레이어를 대장간으로 옮기는 처리였다. 호스트가 결과를 반영할 때 모든 플레이어를 처음 스폰 위치로 옮기는 방법을 제안했다. 전투 씬이 낮 화면을 가린 동안 옮기므로 따로 페이드를 더하지 않는다. `Network/`의 공개 API(`PlayerAreaTravel`, `PlayerSpawner`)를 바꾸는 일이라 사용자 확인을 받고 진행했다.

## 주요 결정

- 결과창에 골드와 토파즈로 늘어난 몫을 다시 보여 준다(사용자 결정).
- 전투 중에는 낮 씬 골드 표시를 숨긴다(사용자 결정).
- 전투 결과창을 닫으면 모든 플레이어가 대장간 스폰 위치에서 다음 날을 시작한다(사용자 결정). 진행 문서에 남아 있던 "다음 날 아침 시작 위치" 항목을 이것으로 정했다.
- "파견하지 않고 다음 날"로 넘길 때는 페이드가 없어 이번에는 옮기지 않는다.
