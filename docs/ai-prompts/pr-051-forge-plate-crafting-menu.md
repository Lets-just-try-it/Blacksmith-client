## 주요 요청

1. 방어구·장신구 제작대를 먼저 작업한다. 프로토타입이 있는 판 성형부터 기능까지 구현한다.
2. 투구·갑옷마다 1~3티어가 들어갈 예정이므로 목록에서 제작할 것을 고르게 하고, 재료 정보를 보여 주며, 재료가 충족되면 제작 버튼으로 미니게임에 넘어가게 한다. 무기·장신구 작업대도 같은 방식을 쓸 수 있게 한다.
3. 재료는 작업대 슬롯에 옮기되, 작업대 슬롯은 별도 창이 아니라 목록 창 안에 두고 필요한 개수 이상은 들어가지 않게 한다.
4. 제작 목록이 떠 있을 때 영업이 끝나면 창이 사라지고, 미니게임이 끝나면 목록이 다시 보이지 않게 한다.
5. 옮긴 것처럼 보이기만 하고 실제 아이템은 제작이 끝날 때까지 개인 인벤토리에 남게 한다.

## AI와 논의한 내용

### 재료를 어디서 확인할까

손에 든 물건, 인벤토리 전체 자동 확인, 작업대 슬롯에 실제로 옮기기를 검토했다. 사용자는 인벤토리에서 작업대 슬롯으로 옮기는 방식을 골랐고, 구현 뒤 인벤토리 확인으로 바꿨다가 다시 슬롯 방식(창 안, 개수 제한)으로 돌렸다.

### 실제 이동과 예약

작업대 슬롯을 네트워크 인벤토리로 만들면 재접속·연결 끊김 때 남은 재료 처리가 필요했다. 사용자가 "옮긴 것처럼 보이게만, 실제로는 제작 완료까지 개인 인벤토리에 남게" 하자고 해서 칸별 개수를 예약하는 방식으로 바꿨다.

### 판 성형 선택을 제작 목록으로

판 성형 안의 투구/갑옷 선택 화면은 제작 목록의 항목 선택으로 대체했다.

## 주요 결정

- 사용자 결정: 판 성형 선택을 제작 목록으로 대체, 작업대 슬롯을 창 안에 두기, 필요 개수까지만 놓기, 예약 방식, 미니게임 종료·영업 종료 때 창 닫기, 재료 개수를 이번 작업에 포함, 항목이 하나뿐인 작업대도 목록을 보여 주기, 인벤토리 영역 파일은 최소 수정 허용.
- 구현 중 확정: 판 성형은 주괴를 투구 2개·갑옷 4개 쓴다([추정]). 항목을 바꾸면 예약을 모두 푼다. 철 투구/갑옷도 목록에 올린다. 미스릴은 아이템이 없어 제외한다.
- 기획 변경: `GAME_CONCEPT.md` 4.3과 `NETWORK_DESIGN.md` 4·5절을 고쳤다.
